# Comunidade do Livro

Site de apresentação: https://ssseiva.github.io/comunidadedolivro/

O texto não mora aqui. Ele fica no cofre do Obsidian, em
`01 Projetos/Cursos/Comunidade do Livro/site de apresentação.md`.

Para atualizar o site: editar a nota e dar duplo clique em `publicar.cmd`
(ou no atalho "Publicar Comunidade do Livro" na área de trabalho).
O script copia a nota para `index.md`, faz o commit e envia.
O GitHub Pages monta a página em 1 ou 2 minutos.

O visual fica em `_layouts/default.html`. A fonte dos títulos é a Register, em `fontes/`.
